## Описание

Система состоит из трёх взаимодействующих агентов:

- **Observer** — анализирует ответы кандидата на предмет достоверности, выявляет галлюцинации, копипаст и попытки манипуляции
- **Manager** — управляет стратегией интервью, определяет покрытие тем и корректирует план
- **Interviewer** — ведёт диалог с кандидатом, формулирует вопросы и адаптирует их сложность

## Возможности

- Адаптивная сложность вопросов в зависимости от уровня ответов
- Скрытая рефлексия агентов (internal thoughts)
- Детекция галлюцинаций и недостоверных ответов
- Устойчивость к off-topic вбросам и попыткам сменить тему
- Структурированный финальный фидбэк с вердиктом
- Сохранение полного лога интервью в JSON

## Запуск

```bash
python interview_agent.py
```

После запуска доступно меню:

1. Интерактивный режим — ручное прохождение интервью
2. Сценарий: Сильный кандидат
3. Сценарий: Слабый кандидат
4. Сценарий: Средний кандидат
5. Сценарий: Манипулятор
6. Сценарий: Молчун
